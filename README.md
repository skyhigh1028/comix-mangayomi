# Comix Mangayomi Extension

A personal Mangayomi JavaScript source for Comix.

## Repository URL

`https://raw.githubusercontent.com/skyhigh1028/comix-mangayomi/main/index.json`

## Source

The extension uses the Comix API proxy at https://comix-api.vercel.app/ for search, metadata, chapters, and reader pages.

## Disclaimer

For personal use. Respect the rights of manga/comic publishers, authors, artists, and the Comix service.
